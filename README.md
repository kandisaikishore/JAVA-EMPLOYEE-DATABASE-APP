# Employee Database App (JDBC)
A simple Java application that connects to MySQL using JDBC and performs CRUD operations on an employee table.

## Features
- Add Employee
- View Employees
- Update Employee
- Delete Employee

## Tools
- Java
- MySQL
- JDBC Driver

## How to Run
1. Create MySQL DB and table.
2. Update DB credentials in code.
3. Run EmployeeDBApp.java.
